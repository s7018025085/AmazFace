# Watch Face Designer (Zepp OS)

Локальный визуальный редактор циферблатов для Zepp OS. Собирайте интерфейс мышкой,
получайте на выходе реальный `index.js` для Watch Face (API_LEVEL 3.0 / 3.5 / 4.0 / 4.2).

Читайте **`ZEPP_API_COMPONENTS.md`** — это исследование реального Zepp OS API
(`hmUI.*`), на основе которого построен реестр компонентов `src/components/registry.js`.
Компоненты, чьи свойства не были стопроцентно подтверждены документацией,
помечены значком ⚠ прямо в палитре и в Inspector.

## Запуск

Никаких зависимостей не требуется — чистый HTML/CSS/JS (обычные `<script>`, без
`type="module"`), поэтому **`index.html` можно просто открыть двойным кликом**
прямо с диска (`file://...`) в Chrome/Edge — сервер не обязателен.

Если всё же хочется открывать через `http://localhost` (например, для чистоты
относительных путей к ассетам в будущем), можно поднять любой статический сервер:

```bash
npm run dev          # npx serve на :5173
# или
python3 -m http.server 5173
```


## AOD Studio

The integrated **AOD Studio** provides an independent AOD scene alongside Normal:
- switch Normal / AOD without reloading;
- copy all Normal objects or only images, analog hands, or text/data;
- independent Layers/Inspector/Undo/Redo;
- AOD-specific background, brightness preview, test time/date and test sensor values;
- AOD rotation/scale per object;
- AOD config export as `*.aod-config.json`;
- full-project export also includes `aod-config.json` and `AOD_INTEGRATION.md`.

The AOD export is intentionally an editor/configuration adapter. It does **not** invent or claim an official Zepp OS AOD runtime API. Runtime integration must be implemented only after confirming the target firmware/SDK API.

## Возможности

- Палитра компонентов по категориям (Text & Time, Data, Weather, Shapes, Canvas, Image, Analog)
  с drag-and-drop и двойным кликом для добавления.
- Pixel-perfect позиционирование: X/Y/W/H с точностью до 1px, ручки resize, grid + snap-to-grid,
  snap-to-center guides.
- Панель слоёв: показать/скрыть, лок, дублировать, удалить, drag-переупорядочивание, z-index.
- Inspector со свойствами, специфичными для выбранного виджета (не показывает несуществующие поля).
- Подсказки в Inspector: у каждого свойства есть всплывающее пояснение (что это значит на
  устройстве и в каких единицах) — например, чем «Центр X/Y» отличается от «Точки опоры X/Y».
  Отключаются общим переключателем ❔ в меню.
- Удаление компонентов запрашивает подтверждение со списком того, что будет удалено —
  из топбара, из панели слоёв и по клавише Delete.
- Подсказки для компонентов палитры: наведение на любой компонент показывает виджет hmUI, минимальный
  API_LEVEL, статус проверки документацией (✓/⚠) и (если есть) фиксированный источник данных.
- Универсальный компонент «Текст» умеет привязываться к живым данным через поле «Источник данных»
  (Время, AM/PM, Дата, День недели, Час/Минута/Секунда отдельно, День/Месяц/Год отдельно, Батарея,
  Шаги, Пульс, Калории, Дистанция, Погода: температура) — для каждого источника открывается свой
  набор точных настроек (формат, разделители, ведущий ноль, локаль названий месяцев/дней, единицы
  измерения, число знаков после запятой, порог валидности и т.д.), без необходимости заводить
  отдельный специализированный компонент под каждый пресет.
- Готовые пресеты **«Часы (ЧЧ)», «Минуты (ММ)», «Секунды (СС)»** и **«День (ДД)», «Месяц (ММ)»,
  «Год (ГГГГ)»** в палитре (категория «Текст и время») — каждая часть времени/даты выводится
  отдельным TEXT-виджетом со своей позицией, размером и цветом, а не одной строкой целиком.
  Значения обновляются раз в секунду через общий таймер `@zos/timer` (в том числе день/месяц/год —
  чтобы циферблат не «застрял» вчерашней датой при работе через полночь).
- Значок погоды поддерживает **29 состояний** (Sunny, Some clouds, Cloudy, Thunderstorm, разные
  градации дождя/снега, Fog, Sandstorm и т.д.) — список взят не из документации docs.zepp.com (там
  такой таблицы нет), а из реально протестированных на устройстве констант проекта Gadgetbridge
  (см. ZEPP_API_COMPONENTS.md, раздел «Иконки погоды»); честно помечен 🟡 как подтверждённый
  реверс-инжинирингом, а не официальной документацией.
- Undo/Redo (Ctrl+Z / Ctrl+Y) — история хранит состояние БЕЗ загруженных картинок
  (иначе каждый шаг копировал бы все base64-ресурсы); как следствие, добавление и удаление
  ресурса через undo не откатывается, Copy/Paste/Duplicate (Ctrl+C/V/D), Multiselect (Shift+click),
  Align/Distribute для нескольких объектов.
- Zoom 25–400% и pan (Alt+drag / средняя кнопка мыши / Ctrl+scroll) без изменения реальных координат.
- Asset Manager: загрузка PNG/JPEG, превью, переименование, удаление, использование как IMG src
  или фон циферблата.
- Панель «Устройство и сборка»: выбор профиля экрана (Amazfit Balance 2 + геометрические
  пресеты 480×480 / 466×466 / 390×450 / произвольный), ручные размеры и форма, а также
  метаданные app.json — `targetKey`, список `deviceSource`, `appId`, версия, вендор.
  Идентификаторы моделей Designer НЕ угадывает: для пресетов, кроме проверенного Balance 2,
  их нужно взять из app.json своего `zeus create`-шаблона, иначе экспорт блокируется ошибкой.
- Выбор `API_LEVEL` проекта — несовместимые компоненты блокируются в палитре и подсвечиваются
  ошибкой в Inspector/Export.
- Export Validation: ERROR блокирует внимание пользователя, WARNING — предупреждает
  (например, «эффект недоступен в реальном Zepp OS», «неподтверждённое свойство»).
- Export → `index.js`: генерирует `hmUI.createWidget(...)` код под выбранный API_LEVEL,
  со стабильными ID компонентов и маркерами `// USER ANIMATION CODE CAN BE ADDED HERE`
  для последующего добавления анимаций вручную.
- Секундная стрелка: настройка **«Ход стрелки»** — `Тик` (штатный TIME_POINTER, 1 скачок в секунду)
  или `Плавный ход` (sweep). В плавном режиме экспортёр выносит стрелку из TIME_POINTER в отдельный
  IMG-виджет и вращает его вручную из `@zos/timer` с заданной частотой кадров (5–60 к/с) и
  необязательным квантованием угла. Режим помечен ⚠: поворот IMG не подтверждён цитатой из
  docs.zepp.com, плюс предупреждение о расходе батареи и AOD. Кнопка «Проверить стрелки» показывает
  выбранный режим наглядно, с выбором **скорости перемотки** (1×/60×/360×/720×/3600×/43200× —
  от почти реального хода до полного круга часовой стрелки за 1 секунду), которую можно
  переключать прямо во время прогона без скачка стрелок.
- Save/Open проекта как `*.watchface.json`. **Имя файла всегда латиницей**: кириллическое название
  транслитерируется (`Мой циферблат` → `Moy_tsiferblat.watchface.json`), то же для `.zip` и для поля
  `name` в `package.json` экспортируемого проекта.
- Кнопка «Build demo face» — собирает тестовый циферблат (время, дата, погода, пульс, шаги,
  батарея), демонстрируя возможности редактора.

## Исправлено при добавлении раздельных компонентов времени/даты

Пресеты с полем «Формат» (`time_hm`, `time_hms`, `date_full`, `weekday`,
`weather_temp` и новые `time_hour`/`date_month`/`date_year`) раньше «утекали»
служебное поле формата (`format`/`unit`/`hour_format`/...) прямо в объект
`createWidget({...})` как несуществующее для `hmUI.widget.TEXT` свойство —
из-за этого в сгенерированном `index.js` появлялась мусорная строка вида
`format: 'HH:MM', // format applied in code below` внутри самого виджета.
Экспортёр теперь явно исключает все такие «формат/опции»-поля из списка
реальных свойств виджета (см. `DATA_SOURCE_FORMAT_KEYS` в
`src/exporter/index-js-exporter.js`) — они по-прежнему используются, но
только для сборки текста через `getTimeText()/getDateText()/...`, а не как
литеральное свойство `createWidget`.

## Не реализовано (сознательно, см. ZEPP_API_COMPONENTS.md)

- Полноценный `WATCHFACE_EDIT_GROUP` (циферблат, редактируемый конечным пользователем
  на телефоне) — сложная, слабо документированная подсистема.
- Настоящие анимации — оставлены только заготовки в экспортируемом коде.
- Реальный bitmap-градиент фона — доступен только как preview с предупреждением при экспорте.
- Точные имена констант `hmUI.data_type.*` для батареи/шагов/пульса/погоды — вместо угадывания
  Designer генерирует явно помеченные TODO-заглушки с ссылкой на официальную документацию,
  которую нужно свериться перед публикацией (см. правило «не выдумывать Zepp API»).

### Тап-зоны компонентов
У каждого компонента есть группа «Открытие по тапу». Если выбрано приложение или системный показатель,
экспортёр создаёт поверх циферблата прозрачный `BUTTON` с размером зоны компонента. В редакторе такие
компоненты помечаются рамкой `TAP`. Для кругов зона автоматически совпадает с фактическим кругом
(`center_x/center_y/radius`). Для стрелок `TIME_POINTER` используются их `x/y/w/h` — это намеренно
оставлено отдельной редактируемой зоной, потому что стрелка вращается и одна статическая узкая зона
не может следовать за ней.
